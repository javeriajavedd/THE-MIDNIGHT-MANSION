# The Midnight Mansion
### AI Lab Project – Murder Mystery Game

## Project Overview
The Midnight Mansion is an interactive murder mystery game developed in Python using the Tkinter GUI library. Players investigate a mysterious crime by exploring evidence, interrogating suspects, collecting clues, and making the final accusation.

The game combines storytelling, logical reasoning, keyword-based question matching, and interactive decision-making to create an engaging mystery-solving experience.

## Objectives
- Develop an interactive desktop-based mystery game.
- Encourage logical reasoning and evidence-based decisions.
- Implement rule-based question matching for suspect interrogation.
- Provide an engaging user interface with multiple gameplay features.

## Key Features
- Five suspects: Victoria, Marcus, Evelyn, Daniel, and Oliver.
- Six evidence records, including Broken Watch, Wet Footprints, Torn Document, Silver Button, Security Log, and Hidden Note.
- Suspect interrogation through player-entered questions.
- Keyword-based matching and response scoring.
- Preset interrogation questions and answers.
- Evidence collection and notebook features.
- Hints and final accusation system.
- Difficulty levels: Easy, Medium, and Hard.
- Timer, score, and limited lives.
- Feedback, sound effects, and interactive GUI.

## Technologies Used
- **Language:** Python
- **GUI:** Tkinter
- **Concepts:** Functions, data structures, conditional logic, string processing, and event-driven programming.

## AI Concepts
This project uses a rule-based, heuristic-inspired approach for matching player questions with suspect responses.

The system normalizes text, handles selected contractions, checks keyword groups, and scores possible matches to select a response.

**Note:** This project does not use a trained machine learning model or an external dataset. The mystery story, suspects, clues, and interrogation data are predefined within the code.

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file:

   `python "murder_mystery_fixed (2) (2).py"`

5. Follow the on-screen instructions and start investigating.

A compatible desktop environment with Tkinter support is required.
